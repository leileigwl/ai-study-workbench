# Domain Guide: Foreign Language Books & Applied Dialogues (`language`)

Use whenever the learner feeds in a language textbook unit, phrasebook, business-communication guide, grammar reference, or target reading passage (English, Japanese, Spanish, etc.).

## Vocabulary Adaptation
Refer to items naturally as **communicative intent, tone traps, natural phrasing patterns, and live situational dialogue** (not coding terminology).

## 4-Step Source-Driven Flow
1. **Extract from the Material**: Pull target expressions, grammar/register rules, and common learner translation traps into `answer_key.md`.
2. **Blind Workbook (`workbench.md`)**: Present real situations *without* showing the book's model sentences upfront. Ask how the learner would express the intent first, highlighting awkward literal-translation traps in Part 3.
3. **Unlock for Memorization**: Once they revise after targeted tone/intent hints (*"Too blunt—how can you keep the same boundary while offering an alternative?"*), unlock side-by-side **Verified Natural Patterns to Memorize** in `workbench.md`.
4. **Answer-Grounded Mock Simulation**: Run a multi-turn live conversation (client pushback, cafe order complication, job screen, travel check-in) strictly testing whether the learner naturally deploys the exact memorized expressions from the chapter under pressure.
